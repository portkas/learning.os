# 补充

## 1. wc

功能：用于统计文件中的行数，单词数和字节数，也可以用来统计来自标准输入的数据。

1. 基本用法

```bash
$ wc [选项] [文件名]
```

如果没有指定文件名，wc会从标准输入读取数据；


2. 常见选项

- `-l`：统计行数；
- `-w`：统计单词数；
- `-c`：统计字节数；
- `-m`：统计字符数；
- `-L`：统计最长行的长度；


3. 示例

```bash
$ wc p4.c
 32 114 883 p4.c
```

- 32：文件中的行数
- 114：文件中的单词数
- 883：文件中的字节数
- p4.c：被统计的文件名
